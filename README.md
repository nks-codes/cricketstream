# CricketStream.live

GitHub Pages starter for a mobile-first cricket scores website.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- SportScore cricket API
- GitHub Pages

## API
The starter uses:

`https://sportscore.com/api/widget/matches/?sport=cricket&limit=50&src=cricketstream.live`

The free SportScore tier currently requires visible attribution. Do not remove the SportScore attribution link.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Add `cricketstream.live` as the custom domain after DNS is configured.

## Before publishing
- Replace the support email in `contact.html`.
- Add your real AdSense code only after the site is ready and you have been approved.
- Replace placeholder/news content with useful original cricket content.
- Verify every policy page against your actual services and local legal requirements.
- Do not describe the site as “100% AdSense approved”; Google makes the final policy decision.
